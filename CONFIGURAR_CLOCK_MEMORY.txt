CONFIGURACAO DO CLOCK MEMORY - MB10
===================================

Os projetos que precisam de uma luz piscante usam o Clock Memory nativo da
CPU em vez de executar um timer ou chamar SFC64 em todos os scans.

No HW Config da CPU 314C-2 DP:

1. Abra Properties da CPU.
2. Localize a configuracao de Clock Memory / Clock Memory Byte.
3. Habilite Clock Memory.
4. Defina o byte como MB10.
5. Compile e carregue a configuracao de hardware junto com o programa.

Com MB10 configurado pela CPU:

Bit     Periodo     Frequencia     Uso neste repositorio
M10.5   1,0 s       1 Hz           pisca 500 ms ON / 500 ms OFF
M10.7   2,0 s       0,5 Hz         gatilho lento para releitura do RTC no Projeto 5

A CPU atualiza esses bits automaticamente. Eles NAO devem ser escritos pelo
programa do usuario.

Projetos que usam M10.5:
- Projeto 1
- Projeto 2
- Projeto 3
- Projeto 5
- Projeto 6
- Projeto 11
- Projeto 13

Projeto 5 tambem usa M10.7 para evitar chamar SFC1 em todos os scans.

A configuracao de Clock Memory e parte do hardware do S7-300. Sem habilitar
MB10, as fases principais continuam sequenciadas, mas as luzes que dependem
do clock nao piscarao corretamente.
