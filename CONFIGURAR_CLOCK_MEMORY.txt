CONFIGURACAO DO CLOCK MEMORY - MB10
===================================

Habilite o Clock Memory da CPU e configure o byte como MB10.

Bits usados
-----------
M10.0  10 Hz    periodo 0,1 s   -> tick de 100 ms
M10.5   1 Hz    periodo 1,0 s   -> 500 ms ON / 500 ms OFF
M10.7 0,5 Hz    periodo 2,0 s   -> gatilho lento para leitura do RTC

Uso por projeto
---------------
M10.0: Projetos 8, 9 e 10
M10.5: Projetos 1, 2, 3, 5, 6, 11 e 13
M10.7: Projeto 5

A CPU atualiza MB10 automaticamente. O programa nao deve escrever nesse byte.

No HW Config:
1. abra Properties da CPU;
2. habilite Clock Memory;
3. informe MB10;
4. compile e carregue a configuracao de hardware.

Sem essa configuracao, os projetos que dependem desses pulsos nao terao a
temporizacao periodica esperada.
